One-click posting

  1. At linkedin.com/developers, create an app (it needs a LinkedIn Page; your company page works).
  2. Products tab: add Sign In with LinkedIn using OpenID Connect and Share on LinkedIn.
  3. Auth tab: add this redirect URL:
  4. In the Anvil editor → App Secrets: linkedin_client_id and linkedin_client_secret from the Auth tab.

Until then, everyone posts with Copy and open LinkedIn. Hookline never posts on a timer (LinkedIn's API terms forbid automated posting).

LinkedIn retires each monthly API version after about a year. If posting starts failing with HTTP 426, set a recent month here.
